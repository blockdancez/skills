## Summary

GlyPho is a platform that generates editable SVG assets tailored to specific needs, transforming brief prompts into reusable vector families with consistent presets. It emphasizes quality and community involvement, allowing users to create and share SVGs while earning credits. Key features include a visual workflow that enhances prompt consistency, editable exports for various applications, and a reward system for sharing original assets. GlyPho offers multiple style presets such as Minimal Outline, Notion Style, and Duotone, suitable for logos, icons, and illustrations, setting itself apart from conventional stock SVG libraries. Pricing includes a free tier and subscription options for increased access and features.

## A visual workflow built around editable SVG output

GlyPho focuses on prompt quality, preset consistency, private libraries, and community rewards instead of generic stock browsing.

### Prompt with intent

Write what the asset must explain, where it will appear, and which preset should guide the result.

### Preset consistency

Reuse visual lanes so icons, hero art, diagrams, and empty states feel like one SVG family.

### Editable export

Move the SVG into code, docs, decks, or a design file without flattening it into a screenshot.

### Rewarded sharing

Publish original assets when they are useful to others and earn credits without repost loops.
